# T022 게이트 임계 튜닝 — 녹음 가이드 (파트1)

목적: 직접 녹음한 아동 발화 근사 샘플 10~20건으로 STT 실패 게이트 임계값(②no_speech_prob·③avg_logprob)을 실측 튜닝하고 `src/lib/config.ts` 기본값을 갱신한다. 포맷 수용(mp4/webm)은 이미 검증 완료(2026-08-11) — 이번 목적은 **실제 마이크·거리·발화 스타일에서의 신호 분포 측정**이다.

## 1. 준비

- **기기 2종**: iPad(음성 메모 앱 → m4a/mp4 계열)·안드로이드(크롬 기반 녹음 → webm/opus 권장, 녹음기 앱 m4a도 무방). 실제 서비스는 브라우저 MediaRecorder이므로 가능하면 브라우저 녹음 페이지 사용.
- **저장 위치**: 리포지토리 `out/recordings/` (gitignore 대상 — 커밋되지 않음, 폴더는 만들어 둠)
- **파일명 규칙** (라벨이 채점 기준이 됨):

  ```
  {label}__{기기}__{설명}.{확장자}
  예: ok__ipad__또박또박1.m4a / silence__android__빈방.webm / short__ipad__응.m4a
  ```

  | label | 뜻 | 기대 판정 |
  |---|---|---|
  | `ok` | 정상 발화 (문장 답변) | 통과 |
  | `silence` | 무음 (말 없이 5~10초) | 실패 |
  | `noise` | 소음만 (TV·생활소음, 말소리 없음) | 실패 |
  | `short` | 1~2자 발화 ("응", "네") | 실패 |

## 2. 녹음 구성 (총 14~20건, 기기당 절반씩)

**ok 10~14건** — 대화1(며느리) 질문 "내 방귀가 너무 크다는 걸 알면 가족들이 나를 이상하게 생각하지 않을까?"에 대한 답변을 아동 말투로. 내용은 아래에서 골라 **발화 스타일을 다양하게**:

| 스타일 | 예시 문장 |
|---|---|
| 또박또박 | "가족들한테 솔직하게 말해봐. 참으면 배가 아프잖아." |
| 빠르게 | "안 이상해, 방귀는 누구나 뀌는 거야!" |
| 작게/소심하게 | "음… 무서워도 용기 내서 말해보면 좋겠어." |
| 마이크에서 1m 떨어져 | "방귀 참으면 며느리가 너무 힘들어서 그래." |
| 주저하며 (음… 어…) | "어… 그러니까… 가족들은 이해해 줄 거야." |
| 긴 답변 | "며느리가 방귀를 참아서 얼굴이 노래졌으니까, 시아버지한테 사실대로 말하고 마음 편하게 뀌면 좋겠어." |
| 대화3(이장) 답변 | "며느리 방귀로 배나무를 흔들어서 배를 떨어뜨리면 돼요!" |

**silence 2~3건** — 빈 방에서 말 없이 5~10초 / 에어컨·팬 소음만.
**noise 2~3건** — TV 소리나 생활 소음만 5~10초 (말소리 없이).
**short 2건** — "응" / "네" 한 마디만.

## 3. 실측 실행

```bash
npx tsx scripts/stt-tune.ts --scene sc_banggui_03 --reply "ㅇㅇ아, 내 방귀가 너무 크다는 걸 알면 가족들이 나를 이상하게 생각하지 않을까?"
```

(기본 디렉토리 `out/recordings/`. 개별 파일 정밀 확인은 기존 `scripts/stt-check.ts`.)

> ⚠️ **안드로이드 기본 녹음기 앱 주의**: 확장자는 `.m4a`여도 실제 컨테이너가 3GPP(`ftyp3gp4`)라 OpenAI가 400으로 거부한다(실측 2026-08-11). ffmpeg 무손실 재포장 후 실행할 것 (내부 코덱은 AAC라 음향 특성 보존):
>
> ```bash
> npm i --no-save ffmpeg-static   # 1회
> mkdir -p out/recordings-remux
> for f in out/recordings/*.m4a; do node_modules/ffmpeg-static/ffmpeg -v error -y -i "$f" -c copy -f ipod "out/recordings-remux/$(basename "$f")"; done
> npx tsx scripts/stt-tune.ts out/recordings-remux --scene sc_banggui_03 --reply "…"
> ```
>
> 실서비스는 브라우저 MediaRecorder(webm/opus·mp4/AAC)라 이 문제와 무관 — 녹음기 앱 산출물에만 해당.

출력물:

- 파일별 판정 + 게이트 신호 5종
- ok/기대실패 그룹별 신호 분포(min·med·max)
- 오분류 목록 — false accept의 raw 텍스트는 ⑤상투구 목록 추가 후보
- **임계 후보** — `STT_GATE_NO_SPEECH_PROB`·`STT_GATE_AVG_LOGPROB` 권고값 + 권고 적용 시 재판정 결과
- `out/stt-tune-report.json` (신호 원본 — config 갱신 근거로 보존)

## 4. 완료 절차

1. 권고값 검토 → `src/lib/config.ts` `sttGate` 기본값 갱신 (필요시 ⑤상투구 추가)
2. `npx vitest run src/lib/stt/gates.test.ts` — 기본값 정합 테스트 통과 확인
3. `tasks.md` T022 `[X]` 처리, 리포트 요약을 T022 줄에 기록
4. **동기화 포인트 #2**: 파트2에 "`SttResult` 인터페이스 전달 완료" 선언
