## 4. 컨벤션

- **임포트**: `src/` 하위는 `@/` 별칭 사용 (예: `@/lib/rules`)
- **네이밍**: API·코드는 camelCase, DB 컬럼은 snake_case — 경계에서 매핑 (연동기준_충돌검토 §1-6)
- **판단은 코드**: 대화 진행 판정 로직은 `src/lib/rules/`의 순수 함수에만 둔다. LLM 호출부에 판단 로직을 넣지 않는다
- **API 키**: 모든 외부 API 호출은 Route Handler(서버)에서만. 클라이언트 번들에 키가 들어가지 않게 한다
- **문서**: 기획·분석 산출물은 `docs/` 하위 분류 디렉토리(기획·모델선정·설계검토·프로젝트)에 한글 파일명으로 유지. 개발 판단 우선순위는 CLAUDE.md SSOT(2026-08-10 확정) — 기본은 `docs/` 설계 문서, 문서 간 충돌 시 기능명세서 우선, 충돌 발견은 `specs/001-goodquestion-mvp/`에 기록 후 팀 공유
