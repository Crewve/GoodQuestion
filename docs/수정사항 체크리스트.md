## C. 품질 개선 (LLM·성능·QA)

- [ ] **C1. LLM 생성 표현 고도화** *(테스트 리스트)* — 어색한 표현·유도 질문 반복(대화 늘어짐 체감) 개선. T073~T075로 프롬프트 보강 5건+시나리오 회귀가 이미 반영됐으므로, **staging 실사용 로그(`utterance_analyses`·messages) 리뷰 → 어색 패턴 수집 → 프롬프트/시나리오 추가**의 반복 사이클로 진행. 필요 시 `GENERATION_MODEL=gpt-4o` 한 줄 상향(모델 보고서의 예정된 플랜, 미실행 상태)
- [ ] **C2. 장면 전환 프리로드** *(테스트 리스트)* — 이미지가 자막보다 늦게 뜸. 고정 TTS 사전 생성·Storage 적재는 이미 구현됨 → 잔여는 **다음 장면 이미지/오디오 프리로드**(이야기 시작 시 or 장면 진입 시). play 계열은 T069 next/image 전환도 미적용 상태라 함께 검토
- [ ] **C3. 캐릭터 생성 발화 음성 QA 재확인** *(테스트 리스트)* — 코드 경로는 정상(TTS 캐시→audioUrl, 실패 시 텍스트 폴백). 당시 원인으로 유력한 자동재생 차단은 `useAudioUnlock`+NotAllowedError 복구("다시 듣기" 안내)로 처리돼 있음 → **실기기 QA로 재현 여부만 확인**. 함께 적힌 콘솔 에러(`A listener indicated an asynchronous response…`)는 크롬 확장 프로그램 노이즈로 앱 코드와 무관
