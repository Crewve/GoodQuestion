## 미션 노출 원칙

미션은 대화 시작과 동시에 보여주지 않는다. 아이의 발화 흐름을 확인한 뒤, 해결 방법을 실제로 구성해야 하는 시점에 노출한다.

```
캐릭터 첫 대사
→ 아이가 자유롭게 해결 방법 제안
→ 해결 방향이 나타나는지 확인
→ 구체적인 실행이 필요한 시점 판단
→ 미션 노출
→ 아이가 미션 수행
→ 미션 결과를 다음 대화에 반영
```

처음부터 미션을 보여주면 아이가 정해진 답을 찾으려 할 수 있으므로, 캐릭터의 질문에 먼저 아이가 자신의 생각을 말하게 한 뒤에 노출한다.

### 공통 노출 조건 예시

다음 중 하나에 해당할 때 미션을 노출한다.

- 아이가 며느리의 방귀를 활용할 수 있다고 제안한 경우
- 아이가 해결 방향은 말했지만 방법이 구체적이지 않은 경우
- 2회 이상 대화했지만 실행 방법이 나오지 않은 경우
- 캐릭터 질문만으로 해결 방법을 구체화하기 어려운 경우

## 대화3 — 미션1

### 미션1 목적

높은 배나무의 배를 떨어뜨리기 위해 며느리의 큰 방귀를 안전하게 사용하는 방법을 구성한다.

미션 결과는 단순 정답 여부가 아니라 다음 요소 확인에 활용한다.

- 무엇을 사용할 것인지
- 왜 그 방법이 가능한지
- 며느리에게 어떻게 부탁할 것인지
- 그 결과 어떤 일이 생길지

### 대화3 진행 흐름

```
전개3 종료
→ 캐릭터 첫 대사
→ 아이 해결 방법 제안
→ 발화 분석
→ 미션 노출 조건 확인
→ 필요 시 미션1 노출
→ 미션 수행 결과 수집
→ 부족한 목표 요소 추가 질문
→ 목표 충족 또는 최대 턴 도달
→ 캐릭터 마지막 대사
→ 다음 화면 이동
```

## 대화4 — 미션2

### 미션2 목적

친구나 주변 사람의 특징을 다른 관점에서 바라보고, 단점처럼 보이는 특징을 장점이나 가능성으로 바꾸어 말한다.

**미션 내용**: 처음에는 단점처럼 보였지만 좋은 일에 쓸 수 있는 특징 찾기

**예시**

- 목소리가 큰 친구는 멀리 있는 사람을 부를 수 있어요.
- 질문이 많은 친구는 새로운 생각을 찾을 수 있어요.
- 힘이 센 친구는 무거운 물건을 옮길 때 도울 수 있어요.
- 조용한 친구는 다른 사람의 말을 잘 들어 줄 수 있어요.

### 미션2 노출 시점

```
아이가 며느리에게 자신의 특징을 부끄러워하지 않아도 된다고 말함
→ 자신의 특징을 긍정하는 이유 확인
→ 다른 사람의 특징으로 관점을 확장할 필요가 생김
→ 미션2 노출
```

처음부터 미션을 보여주면 아이가 정해진 답을 찾으려 할 수 있으므로, 며느리의 질문에 먼저 자신의 생각을 말한 뒤 노출한다.

### 대화4 진행 흐름

```
전개4 종료
→ 캐릭터 첫 대사
→ 아이가 며느리의 특징에 대한 생각 말하기
→ 감정·관점·결과·해결 요소 분석
→ 적절한 발화 시점에 미션2 노출
→ 친구의 특징을 장점으로 바꾸어 말하기
→ 미션 결과를 캐릭터 대화에 반영
→ 목표 충족 또는 최대 턴 도달
→ 캐릭터 마지막 대사
→ 이야기 종료 또는 말하기 후 활동 이동
```
