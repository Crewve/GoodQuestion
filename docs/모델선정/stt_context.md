# 프로젝트: 굿퀘스천 - 아동 음성대화 학습 서비스 아이 발화 STT 선정

## 목적

해커톤 제출용 MVP. 최소비용/최소개발 우선. 실서비스 아님.\
아이가 캐릭터 질문에 음성으로 답 → STT로 텍스트 변환 → 화면 표시 + 세션 저장 + 발화 분석 입력.

## STT 요건 (자료 근거)

- 언어: 한국어 / 화자: 어린이 (부정확한 발음, 짧은 문장, 비문, 의성어·장난 발화 PLAYFUL 포함)
- 흐름: 마이크 자동 활성화 → 발화 → '보내기' 버튼 → 변환. 실시간 스트리밍 불필요, 발화단위 배치 변환으로 충분.
- 기기 1순위: iPad·안드로이드 태블릿(웹앱 가정), 내장 마이크 잡음 변수
- DB: messages.stt_raw_text(원문)와 text(확정 텍스트) 분리 → 후처리 교정 여지
- STT 변환 실패 시 메시지 미생성 → 신뢰도 실패 게이트 필요
- 원본 음성 미저장, STT 변환 텍스트만 처리·저장(기획 문서 명시) — 오디오는 변환 후 즉시 폐기
- 발화 유효성 분류 존재: VALID/SHORT/UNCLEAR/OFF_TOPIC/PLAYFUL

## 아동 STT 핵심 난제 (선정 기준)

- 성인 위주 학습 모델은 아동 발화 WER 상승
- 짧은 발화 잘림/누락, 무음 구간 환각(Whisper 계열)
- 평가 축: 아동·단문 강건성 / confidence 제공 여부(실패 게이트) / 커스텀 어휘 힌팅 지원 / 비용·통합난이도

## 후보

- OpenAI Whisper API(whisper-1, \~$0.006/분) 또는 gpt-4o-mini-transcribe: 최속 통합, 짧은발화 환각 주의(후처리 필요)
- Google Cloud STT: 한국어 강함, speech_contexts 힌팅, confidence 제공, 60분/월 무료
- 네이버 클로바 스피치 등 국내 특화: 국내 발음 유리, 무료 크레딧

## 정확도 보정 전략 (모델 무관 공통, 필수)

- 커스텀 어휘/프롬프트 힌팅: 현재 스토리의 캐릭터명·핵심단어 주입
- 실패 게이트: confidence 낮거나 빈 결과면 메시지 미생성 + "다시 말해줄래?" 재시도
- stt_raw_text 원문 보존 + text는 경량 LLM 후처리(맞춤법·조사 교정)로 분석 정확도 향상

## 결론

Whisper API(또는 Google STT 무료티어) + 힌팅 + 실패게이트 + LLM 후처리.
