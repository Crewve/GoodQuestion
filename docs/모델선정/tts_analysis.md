## 2. 확정 방안 — 무료 플랜 보유 한국 서비스 비교 (기성 TTS 보이스 배정)

세 후보 모두 한국 기업으로 **한국어 발음·억양 품질, 한국어 문서, 국내 결제·리전**(API 왕복 지연에 유리)이라는 공통 이점 보유.

| 구분 | **타입캐스트 API** ⭐추천 | 수퍼톤 API | 클로바 보이스 API | 클로바더빙 (웹, 보조용) |
| --- | --- | --- | --- | --- |
| **모델/방식** | 한국어 캐릭터·연기 보이스 수백 종(아동·노인·사극 톤 포함), 감정/스타일 파라미터. 네오사피엔스(한국) | 보이스 라이브러리 + 감정 표현 특화 합성. 수퍼톤—하이브 계열(한국) | 한국어 페르소나 보이스 100여 종(아동 보이스 포함), REST API. 네이버클라우드 | 웹 에디터에서 수동 생성·다운로드(API 아님) |
| **예상 비용 (무료 티어 포함)** | **무료 플랜: 매월 30,000크레딧 = 월 3만 자, 동시 호출 2.** 고정대사 사전 생성(수천 자)+캐싱 적용 런타임이면 무료 한도 내 가능성 높음. 초과 시 Light $15/월(20만 크레딧, 초과 $0.09/1천 크레딧). **총 예상: $0\~15** | 무료: 가입 시 매월 3,000크레딧(≈오디오 45분·한국어 약 1만 자 상당). 초과 시 Starter $2.99\~. **총 예상: $0\~3** | **무료 티어 없음.** 앱당 기본료 + 기본 제공 100만 자 합산 구조(정확 단가는 NCP 콘솔 확인 필요). 신규 가입 크레딧으로 충당 가능하나 절차 필요. **총 예상: 수천\~수만 원** | **무료 플랜: 월 15,000자·다운로드 20회, 출처 표기 필수.** 고정대사 배치 생성용으로만 활용 가능 |
| **장점** | **무료 한도가 후보 중 최대(월 3만 자)**, 전래동화 캐릭터에 맞는 연기 톤 보이스가 가장 풍부, 한국어 문서 | 감정 표현 품질, 즉시 클로닝 보유 | 발음·억양 안정성 최상급, 네이버 인프라 | 비용 0으로 고정대사 음원 확보, 아동 보이스 선택 가능 |
| **단점** | 무료 플랜 동시 호출 2(단일 데모 기기면 무관), 스튜디오 무료판은 출처 표기 조건 | 무료 크레딧이 글자 기준으로는 작음(월 1만 자 상당) | 무료 티어 부재 + NCP 가입·콘솔 절차로 초기 마찰 최대 | API가 아니라 **가변 질문(런타임) 대응 불가**, 수동 작업, 출처 표기 |
| **웹앱 통합 난이도** | **낮음** — REST → 오디오, 한국어 개발 문서 | **낮음** — REST, 콘솔에서 키 즉시 발급(계정당 3개) | **중간** — NCP 계정/인증 절차 후엔 단순 REST | 통합 대상 아님(파일만 산출) |
| **복수 캐릭터 구분** | **캐릭터당 다른 프리셋 배정만으로 완결**(며느리=젊은 여성, 시아버지=노년 남성, 이장=중년 남성) + 감정 파라미터 차등 | 보이스 라이브러리에서 배정 + 감정 차등 | 페르소나 보이스 배정(아동·노년 등 다양) | 보이스 선택 후 파일별 저장 |
| **아동 청자 적합성** | 상 (아동·연기 보이스 보유) | 상 (감정 표현) | 상 (아동 보이스 보유) | 중\~상 |

**결론:** 1순위 **타입캐스트 API 무료 플랜**(무료 한도 최대 + 캐릭터 보이스 최다). 클로바 보이스 API는 무료 티어 부재로 후순위, 클로바더빙은 고정대사 무료 배치 생성 **보조 수단**으로만.

## 3. 런타임 아키텍처 (텍스트 다이어그램)

**"고정대사 = 사전 준비 오디오 재생 / 가변질문 = 런타임 TTS"** 구조.

```
┌────────────────────────────────────────────────────────────┐
│  태블릿 웹앱 (iPad / Android, 브라우저)                       │
│                                                            │
│  · 첫 터치 시 오디오 언락 (iOS Safari 자동재생 정책 대응)       │
│  · <audio> 재생 공통 모듈                                    │
└──────────┬─────────────────────────────┬───────────────────┘
           │ ① 고정 대사                  │ ② 가변 질문
           │    (scene_id, character)    │    (LLM 생성 텍스트, character)
           ▼                             ▼
┌─────────────────────┐   ┌────────────────────────────────────┐
│ 정적 오디오 저장소     │   │ 백엔드 TTS 프록시 (API 키 은닉)        │
│ (정적 호스팅/CDN)     │   │                                    │
│                     │   │  1. 캐시 조회: hash(캐릭터+텍스트)     │
│ /audio/{scene}_     │   │     ├─ HIT  → 캐시된 mp3 반환         │
│   {character}.mp3   │   │     └─ MISS → ↓                     │
│                     │   │  2. 캐릭터→voice_id 매핑 테이블 참조    │
│ ← 타입캐스트로 사전    │   │  3. provider 어댑터 → 타입캐스트 API   │
│   배치 생성(1회)      │   │     호출 → 오디오 캐시 저장·반환        │
└─────────────────────┘   └──────────────────┬─────────────────┘
                                             ▼
                          ┌──────────────────────────────────┐
                          │ 타입캐스트 API (무료 플랜, 월 3만 자) │
                          │  · 캐릭터별 프리셋 voice_id 3종      │
                          └──────────────────────────────────┘
```

**설계 포인트**

- **provider 어댑터:** `synthesize(text, voice_id) → mp3` 인터페이스 하나만 두면 무료 한도 소진 시 폴백(수퍼톤/클로바)이나 벤더 교체가 설정 1개로 해결. 지금은 타입캐스트 구현체 하나만 작성.
- **런타임 캐시:** 가변 질문도 LLM이 유사 문장을 반복 생성하므로 `hash(캐릭터+텍스트)` 키 캐시로 API 호출량(=무료 크레딧 소모·지연)을 추가 절감.
- **키 은닉:** TTS API 키를 브라우저에 노출하지 않도록 반드시 백엔드 프록시 경유.
- **iOS 자동재생:** 사용자 제스처 없이 `audio.play()` 불가 → 세션 시작 버튼 터치 시 무음 재생으로 오디오 컨텍스트 언락.

## 4. 최종 권장안 + 실행 체크리스트

**타입캐스트 API 무료 플랜 단독 — 총 예상 비용 $0 (한도 초과 시에만 Light $15 단기 결제)**

**즉시 실행 체크리스트**

1. 타입캐스트 API 가입 → API 키 발급 (무료 플랜, 월 3만 크레딧)
2. 캐릭터 3종 보이스 선정·확정: 며느리(젊은 여성/코믹), 시아버지(노년 남성), 이장(중년 남성) → `캐릭터→voice_id` 매핑 테이블 작성
3. 고정 대사(`story_scenes.character_opening/closing`) 전량 **배치 생성 스크립트 1회 실행** → 정적 호스팅에 mp3 업로드 (수천 자 소모)
4. 백엔드 TTS 프록시 구현: provider 어댑터(타입캐스트) + `hash(캐릭터+텍스트)` 캐시
5. 웹앱: 첫 터치 오디오 언락 + `<audio>` 공통 재생 모듈
6. 크레딧 소모 실측(세션 10회) → 시연일까지 사용량 재추정, 초과 예상 시에만 Light $15 결제 또는 클로바더빙 무료(월 1.5만 자, 출처 표기)로 고정대사 물량 분산

**선정 근거**

- 무료 한도 최대(월 3만 자) + 전래동화 캐릭터 연기 톤 보이스 최다 → "최소비용" 축.
- REST + 한국어 문서 + 프리셋 배정만으로 캐릭터 구분 완결 → "최소개발" 축.
- 한국 기업(발음·억양 품질, 국내 결제·리전) → 한국어 사용 환경 친화 조건 충족.
- 탈락 사유 요약 — 클로바 보이스 API: 무료 티어 부재 + NCP 가입 절차 / 클로바더빙: API 부재로 가변 질문 대응 불가(보조 수단) / 수퍼톤: 무료 크레딧이 글자 기준으로 작음(클로닝 강점은 현 시점 불필요).

## 5. 참고 — v1(글로벌 서비스) 비교 결론 요약

v1에서는 ElevenLabs(클로닝+프리셋 단일 API, Starter $5), Google Cloud TTS(월 100만 자 무료), Azure(월 50만 자 무료), XTTS-v2(오픈소스 자체 서버)를 비교해 ElevenLabs 단일 벤더를 권장했었다. 글로벌 서비스는 무료 글자 한도(Google/Azure)는 크지만 ▲한국어 억양의 부자연스러움(다국어 범용 모델) ▲캐릭터 연기 톤 부족 ▲영어 문서·해외 결제 등 한국어 사용 환경 친화성이 낮아, v2부터 국내 서비스 기준으로 재선정했다. Google TTS 무료 티어(월 100만 자)는 국내 서비스 크레딧이 전부 소진되는 비상 상황의 최후 폴백으로만 남겨둔다.
