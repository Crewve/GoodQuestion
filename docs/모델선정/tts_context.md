# 프로젝트: 굿퀘스천 - 아동 음성대화 학습 서비스 캐릭터 음성(TTS) 선정

## 목적

해커톤 제출용 MVP. 최소비용/최소개발 우선. 실서비스 아님.\
캐릭터가 아이에게 질문/반응하는 음성을 생성해야 함.

## 캐릭터 발화 두 종류 (자료 근거)

- 고정 대사: story_scenes.character_opening / character_closing. 텍스트 사전 확정. 개수 유한. 사전 녹음/사전 생성 가능.
- 가변 질문: 아이 발화 분석 후 부족 요소 유도 시 캐릭터 LLM이 런타임 생성(GUIDED 모드). 실시간 TTS 필요.

## 기타 요건

- 언어: 한국어 / 청자: 어린이 / 기기 1순위: iPad·안드로이드 태블릿(웹앱 가정)
- 캐릭터 예: 방귀쟁이 며느리, 시아버지, 마을 이장 등 복수 캐릭터(목소리 구분 필요)
- STT는 아이 음성→텍스트 변환용으로 별도 존재(본 분석의 주제 아님, 보조로만 언급)

## 방식 (성우 녹음 없음 확정)

- 기성 TTS 보이스 캐릭터별 배정. 고정대사는 사전 배치 생성 후 파일 캐싱, 가변질문만 런타임 호출.

## 아키텍처 결론

"고정대사=사전 준비 오디오 재생 / 가변질문=런타임 TTS".
