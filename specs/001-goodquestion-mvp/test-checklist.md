## B. 화면 스모크 테스트

화면 이동 경로 전체가 깨진 곳 없는지 빠르게 1회 순회한다. 문구는 기능명세서 원문 기준.

### B-1. 인증·프로필 (US3)

- [x] B-1a. (파트1) 회원가입 2단계 → 이메일 로그인 → 로그아웃 후 재로그인. 오류 3종 문구(미가입/비밀번호 오류/형식) 구분 노출
- [x] B-1b. (파트1) 카카오 버튼 — **콘솔 설정 전이면 실패 문구만 확인**(설정 완료 시 PKCE 왕복까지)

### B-2. 이야기·대화 (US1·US2)

## C. T060 장애 폴백 리허설 (공동) — 폴백 매트릭스 전항

> ⚠️ 키 조작 전 `.env.local` 백업. **각 항목 후 원상복구 + dev 서버 재시작.** 진행 중 세션 하나를 대화 장면까지 만들어 두고 시작하면 빠르다.

- [x] C-1. **TTS 장애 — 캐시 미스 시 텍스트만 표시**: `TYPECAST_API_KEY`를 오염(오타)시키고 재시작 → 대화 진행 → 신규 합성이 필요한 캐릭터 응답이 **텍스트만 표시**(오디오 없이 진행 가능), 내레이션은 "다시 듣기" 재시도 동작
- [x] C-2. **TTS 장애 — CLOSING 무영향**: 같은 상태에서 대화를 종료 조건까지 진행 → CLOSING 대사가 **사전 생성본(fixed-audio)으로 정상 재생** (quickstart §4-8)
- [x] C-3. **분석/생성 LLM 장애 — 1회 재시도 후 고정 대사 폴백**: `ANALYSIS_MODEL=존재하지-않는-모델` 오버라이드로 분석만 장애 유발(키 전체 오염 금지 — STT까지 죽음) → 발화 보내기 → 서버 로그에서 1회 재시도 확인 → 고정 대사 폴백(시스템 안내 또는 클로징 조기 전환)으로 **평가·지적 없이** 진행. `GENERATION_MODEL`도 동일 방식 1회
- [x] C-4. **Whisper(STT) 실패**: `OPENAI_API_KEY` 오염 후 재시작 → 녹음 보내기 → `failed: true` 경로로 "다시 한번 말해줄래?" 재시도 안내, **메시지 미생성**(DB에 발화 행 없음 — 파트2가 확인)
- [x] C-5. **max_turns 직전 응답 지연 — 타임아웃 강제 종료**: max_turns 직전 턴에서 브라우저 devtools로 `/api/turn` 응답을 지연/차단 → 무한 대기 없이 타임아웃 후 최대 턴 종료 로직(클로징) 강제 적용
- [x] C-6. **원상복구 확인**: `.env.local` 복원 → 재시작 → 정상 대화 1턴 왕복 성공
